# Aubrey's White Space

*A little space for everything I like.*

Aubrey's White Space is a personal Balatro content mod featuring custom Jokers, consumables, and other ideas inspired by things I'm into.

This project is a work in progress. More content and features will be added over time.

## Contents

- Custom Jokers
- Custom consumables
- Experimental gameplay ideas
- More surprises to come

## Requirements

- [Balatro](https://store.steampowered.com/app/2379780/Balatro/)
- [Lovely Injector](https://github.com/ethangreen-dev/lovely-injector)
- [Steamodded](https://github.com/Steamodded/smods)

Use versions compatible with your installed Balatro version and follow the official installation instructions for each dependency.

## Installation

1. Install Lovely Injector and Steamodded.
2. Download the latest release of Aubrey's White Space from code>download as zip.
3. Place the mod folder in `%AppData%/Balatro/Mods/`.
4. Launch Balatro and check the Mods menu to confirm it loaded.

## Compatibility

Compatibility with other mods has not yet been tested. Please report any issues with details about your Balatro version, Steamodded version, and other enabled mods.
